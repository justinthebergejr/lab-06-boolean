# Lab 06 - Boolean Logic 
### Jacob Provencher and Justin Theberge Jr

In this lab, we learned to play with circuits and how they work. This involved us using our tools to create different types of contraptions

- First, we created a secure door that only opens using a specific order of levers (true or false). A total of 12, with 4 that opened the door in the specific combination.

- We also created a two switch light setup where one switch turned on the light, and the other would turn it off, and vice versa.

- For a other simple contraption, we created a true or false system where the light will light up red if the lever isn't pulled and green if it is pulled.
